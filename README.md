LocalMark operates a public directory of Agent Cards, enabling developers and publishers to discover and verify A2A agents. Based in Madeira, Portugal, it aggregates publicly submitted cards, checks their availability every 6‑12 hours, and provides searchable listings, pricing information, and API documentation for integration.

**Areas:** Company · Directory · A2A · API · Portugal

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for LocalMark: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
